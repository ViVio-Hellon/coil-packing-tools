# 変更履歴(統合アプリ)

## 版の決まり

版は**統合ツールの版と3機能の版を分けて**持ちます(`common/versions.py`)。混ぜません。

| 種類 | 出どころ | いつ上げるか | 変更履歴 |
|---|---|---|---|
| 統合ツールの版 | `config/app.json` の `version` | **配るたび。** 統合画面・共通部分・起動/停止/配布を変えたとき、または機能の版が1つでも上がったとき | このファイル |
| 梱包明細の版 | `modules/packing_details/config/app.json` | 梱包明細の中身(画面・計算・印刷・DB)を変えたとき | `modules/packing_details/docs/変更履歴.md` |
| ペナラベルの版 | `modules/packing_pena_label/app/config.py` の `APP_VERSION` | ペナラベルの中身を変えたとき | `modules/packing_pena_label/docs/変更履歴.md` |
| 資材計算の版 | `modules/packing_material_calculation/config/app.json` | 資材計算の中身を変えたとき | `modules/packing_material_calculation/docs/変更履歴.md` |
| 移植元の版 | 各機能の `__init__.py` の `PORTED_FROM` | 変えない(取り込んだときの記録) | ― |

- 機能の番号の付け方は、その機能のまま(移植元と同じ「メジャー.マイナー.パッチ」)
- 画面の帯の版(`VER1.0.0`)を押すと、統合ツールと3機能の版・移植元が並んで出ます。
  タブにもそれぞれの機能の版が出ます
- **起動時の入れ替え判定は、統合ツールの版と3機能の版の組で比べます。** 機能の版だけを
  上げて配っても、古いプロセスに合流せずに入れ替わります
- CSS・JS の URL には「版-中身の指紋」が入るので、版を上げ忘れても古いものは使われません
- 配布メモ(`配布メモ.txt`)・起動時のログ・`/api/health` にも、4つの版が分けて出ます

### 1.0.4

移植漏れの点検の「低」を直した(これで点検の 17 件は全部済み)。

- **`__pycache__` をアプリのフォルダに作らない**ようにした(ペナラベルの移植元にあった処理)。
  書き先はローカル領域の `pycache\`。アプリ一式を共有フォルダに置いても、端末ごと・Python の
  版ごとのキャッシュで配布フォルダが汚れない。停止(`stop.bat`)も作らない
- 起動のたびに、**3機能の手元の領域を作れて書けるか**を確かめる(書けなければ理由を出して起動
  しない)。起動ログに、3機能の設定ファイルの読み込み失敗・手元DBの置き場所(共有の上に置かれて
  いれば警告)を残す(梱包明細・資材計算の移植元にあった)
- 移植元でログの置き場所を変えていた環境変数(`PACKING_DETAILS_LOG_DIR` `COIL_TOOL_LOG_DIR`)は、
  画面の表示だけが変わって実際のログは変わらなかった。表示も統合アプリのログの場所にし、残って
  いれば起動ログで知らせる(変えるときは `COIL_PACKING_TOOLS_LOG_DIR`)
- 起動待機画面の段: 先に始めた機能の取り込みが続いていても、最後に知らせた機能の段で上書きされて
  いた。**まだ終わっていない機能の段を並べて**出す。段の目印が「取り込み」から「準備」へ戻らない
- `start_app.py --diagnostic`(`start.bat --diagnostic`)で、3機能とも細かいログまで残す
  (ペナラベルの移植元の `--diagnostic`)
- 止めるときに、ペナラベルの状態DB を閉じる(移植元と同じ)
- **試験**: 3機能の Web の試験(梱包明細 306・資材計算 278・ペナラベル 153)を、統合アプリに
  入口とトークン付きで載せた形でも流す(`tests/test_modules_mounted.py`・`tools/pytest_mounted.py`)。
  入口が付くこと・統合アプリが決めることそのものを確かめる4件だけは、理由と、統合版の形を確かめる
  試験を書いて飛ばす
- **梱包明細 0.13.4**: ログの置き場所(上)、開発用の `scripts/make_golden.py` が統合版の置き場所から
  起動できなかったのを直した
- **ペナラベル 1.5.3**: HTTP の約束を移植元に戻した(画面の経路への POST は JSON の 404・長さを名乗らない
  送信も 1MB まで・静的ファイルが無いときは案内つきの 404・要求を1行ずつログに残す・ふだんのログは
  INFO まで)
- **資材計算 0.2.3**: ログの置き場所(上)、統合画面の中では「このタブを閉じる」を出さない
  (iframe からは閉じられず、閉じると3機能とも閉じるため)

### 1.0.3

移植漏れの点検の「中」を直した。

- **起動中の案内画面の「待たずに使い始める」**が効くようにした。押しても同じ待機画面に
  戻っていた(移植元の梱包明細は、取り込み中でも業務画面へ入れた)。準備中でも統合画面を出す
- 準備中に機能の入口(`/details/` `/material/`)を開くと、機能の待機画面が統合アプリの起動確認を
  読んで「別のアプリが同じポートを使っています」と出て止まっていた。統合アプリの待機画面へ回す
- **統合前の単体版が動いていたら起動しない**ようにした。単体版と統合版は同じ手元のデータ
  (作業状態・手元DB・設定)を使うので、移行の途中で両方が動くと同じデータを書き換える。
  単体版は自動では止めない(保存前の作業を持っているかもしれない)。止め方を案内して終わる
- **機能の停止口**(資材計算の帯の「終了」)にも取り込み中の確認を掛けた。統合アプリの「終了」は
  取り込みの途中なら断るが、機能の停止口は確認を飛ばしてプロセスごと止めていた
- **資材計算 0.2.2**: 帯の「終了」が断られたら理由を出す(以前は結果を見ずに「終了しました」)。
  統合画面の中では「3つの機能とも終わります」と確かめ、止まったら統合画面の外枠も
  「終了しました」を出す(以前は「バックエンドと通信できません」)。
  「このアプリについて」のポート・アプリのフォルダを統合アプリのものにした
- **梱包明細 0.13.3**: 起動確認(`/api/health`)のアプリのフォルダを統合アプリのものにした
  (機能のコードのフォルダは `module_root`)。説明書に統合版の起動・置き場所を書き足した
- **ペナラベル 1.5.2**: 設定画面から「使用ポート」を外した(統合アプリが決めるので、変えても
  効かず、表示される由来も誤っていた)。配布設定にも入れない。単体版で持っていた Access の
  試験(32/64bit の切り替え・ACE の選び方・VBScript の中身)を統合版にも戻した
- 資材計算・ペナラベルの説明書に、統合版の起動・置き場所を書き足した

### 1.0.0

- 初版。梱包明細 (VER 0.13.1)・ペナラベル (v1.5.0)・資材計算 (VER 0.2.0) を
  1つの Flask サーバ・1つの画面(タブ)に統合した。中身は `docs/統合設計.md`
- (初版を配る前に直したもの)自動終了の見張りを**画面ごとに数える**ようにした。
  別タブの印刷ページも心拍を送るので(下の「印刷」)、統合画面のタブを閉じても
  開いている間は終わらない(ペナラベルの移植元の「使っている間は止まらない」を守る)
- (同)資材計算の心拍で、「裏に回った」合図が「閉じた」合図を取り消していたのを直した
  (統合画面を閉じても終わらないことがあった。梱包明細の決まりに揃えた)
- (同)ペナラベルの配布設定の置き場所を、梱包明細・資材計算と同じ `配布設定\<機能>\`
  にした。配布用フォルダを作る処理が3機能ぶんをまとめて入れ、「入れない」を選べば
  どれも入れないようにした(以前は梱包明細・資材計算の分が入らず、ペナラベルの分は
  選ばなくても入っていた)。書き出したときの案内も実際の置き場所を示すようにした
- (同)**印刷**: 3機能とも印刷は別のタブで開く(梱包明細の帳票・ペナラベルの印刷ビュー・
  資材計算のチェックリストと発注票)。統合アプリがこれらの画面に小さな心拍のスクリプト
  (`static/js/tab_alive.js`)を差し込み、**開いているあいだはサーバを止めない**ようにした。
  帳票は紙面で書き足した値をサーバへ保存し、発注票はサーバが覚えている中身から組むため。
  各機能のコードと紙面の中身は変えていない。ペナラベルだけに足していた心拍はこれに一本化した
- (同)**Ctrl+P** は、いま見せている機能の画面を刷るようにした(ブラウザの Ctrl+P は一番外の
  文書を刷るので、そのままでは統合画面の見出しとタブと、画面の見えている部分だけが紙に出た)
- (同)ブラウザが取りに来るアイコン(`/favicon.ico`)に根で答えるようにした(ペナラベルの
  移植元と同じ。印刷ビューを開くたびに 404 が出ていた)
- (同)**版を分けた**: 画面の帯に版の一覧、`/api/health` に `versions` と `version_set`、
  起動時の入れ替え判定を版の組で、静的ファイルの URL に中身の指紋、配布メモと起動ログに
  4つの版。3機能の変更履歴に「統合版への組み込み」を書いた(機能の版は移植元のまま)
