## Q17. マスタを直せるのは誰か  ✅ 回答済み(パスワード)

- **直すにはパスワードが要ります。** 設定の「マスタ編集の認証」で
  入れると、そのアプリが動いている間だけ開きます。
- **30分さわらなければ閉じます。** 現場の端末は共用で、書き先は
  共有フォルダの元ファイルです。開けっぱなしの画面が残っていると、
  次に座った人が気づかずに直せてしまいます。

(2か所に持つと、画面は通したのに保存で断られるが起きます)。

なお、既定のパスワードがこの文書とソースに書いてあることは承知の上です。
守りたいのは**うっかり直してしまうこと**で、悪意のある人ではありません

## Q23. 協豊製作所向け(ｺｲﾙ間は間紙入〇)で、VBA が「型が一致しません」で止まる  ✅ 回答済み(移植のように続きを計算する)

実行時エラー13「型が一致しません」で止まりました**(2026-09-23)。
移植やマクロのせいではなく、VBA `リプラ計算` そのものの不具合です。

```vba
If TempHiki(1, C_コイル間は間紙入) = "〇" Then '協豊製作所向け梱包
  ...
  .本数 = ""                 ' 本数を空にする
End If
...
Dim 中間本数 As Long
中間本数 = .本数              ' 空の文字を Long に入れる → 型が一致しません
```

止まるので、ここから先(HB枚数の数え直し・トータル本数・
間紙入のときの `リプラ計算 = 下本数 × 台数`)は**一度も動いていません**。
1C1260 には受注が1件も無いので、これまで誰も踏まなかったものと
思われます。

**移植は止まらずに、その先を書いてあるとおり計算します**
(HB枚数 = 台数、トータル = 下本数 × 台数)。止まるところまでの欄は
VBA と一致しました。

**回答(2026-09-23): 移植のようにする。** 止めずに、書いてあるとおり
続きを計算します(HB枚数 = 台数、トータル = 下本数 × 台数)。
`coil_tool/ripla_service.py` に注記、`tests/test_ripla.py` で固定。

VBA 側も直すなら `中間本数 = val(.本数)` にすれば止まらなくなります
(こちらでは VBA は直していません)。

## Q24. ﾎｲｰﾙで収まるパレットが無いとき、VBA が負の台数を出す  ✅ 回答済み(移植は断る)

疑似ロット Q1201A0(包装仕様 1C1201・ﾎｲｰﾙ)で、VBA は
「収まるパレットがDB上にありません」と知らせたあと**止まらずに
計算を続け**、画面に次の値を出しました。

| 積数 | 台数 | 総高さ | HB枚数 |
| --- | --- | --- | --- |
| -1 | -5 | -190 | -10 |

パレットが決まらないまま高さの制限で割っているためです。
マスタのﾎｲｰﾙのパレットは H1(W720)1件だけです。ﾎｲｰﾙは巾の上下限を
見ず **Ｗだけで判定**する(VBA `PalletSize` の Else の枝)ので、
**外径720を超えると収まりません**(Q1201A0 は外径900)。

> 最初「巾の上下限が空欄なのでどの外径でも収まらない」と書きましたが、
> 誤りでした。外径720以下なら H1 に収まります。

**回答(2026-09-23): 移植は断る。** ﾎｲｰﾙで収まるパレットが無ければ、
積数に関係なく計算を断ります(計算Start・積数の手直しの両方)。

> これも訂正です。回答をいただく前の移植は「パレットが無いから」では
> なく「高さで割った積数が0以下になったから」断っていました。高さに
> 余裕のある値だと、パレット欄が空のまま計算を続けていました。
> 回答どおり「パレットが無ければ断る」をはっきり書きました。

- 断ると台数が空のままなので、チェックリストへ積もうとしても
  「先に計算してください」で止まります(負の値が発注まで届かない)
- **ﾎｲｰﾙだけです。** ほかの種類(全面・スカシ・EXPS など)で収まる
  パレットが無いときは、VBA と同じく知らせたうえで計算を続けます
  (パレット欄は空のまま)。広げるかどうかは決めていません
- 実装は `pallet_service.REFUSE_WITHOUT_PALLET`、試験は
  `tests/test_calc_chain.py`
