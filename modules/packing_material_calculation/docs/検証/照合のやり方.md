## 疑似ロットの結果(2026-09-23)

**19件中17件が、空欄・トータルリプラ本数まで含めて一致。**
対照の Q0118A0 は実物の L6052G0 と同じ答えになったので、マクロの計算
手順は本物の計算Start と同じです。

残り2件は**VBA のほうがおかしい**もので、移植はあえて合わせていません
(表の「既知の違い」に理由つきで記録し、その欄だけ比べない):

以外(チップ・外装紙・クラフトなど)のとき、VBA はトータルリプラ本数に
**0** を出しますが、移植は空欄でした。`リプラ計算` は途中で抜けると
戻り値の既定値 0 を返し、計算Start がそれを書くためです(10件で差が出ていた)。

照合も厳しくしました。**空欄も比べます**(VBA が途中で止まって空の
ままの欄を、以前は見落としていたため)。トータルリプラ本数も比べます。

## 疑似ロット ── 来ない仕様をロットを待たずに確かめる

**Alt+F8 →「照合_疑似ロットをまとめて計算」を1回押すだけ**です。
マクロに入っている19件の疑似ロットを、1件ずつ画面に入れて計算し、
書き出します(1件目のあと知らせは出ません。途中でVBA自身の知らせが
出たら OK を押してください)。

- **計算Start が読む画面の欄は8つだけ**(包装仕様NO・外径・製品単重・
  受注板厚・受注板幅・検入数・梱包単位_重量・梱包単位_枚数)で、残りは
  梱包資材マスタ。この8欄を `フォーム展開` と同じ書式で画面に入れれば、
  台帳に無いロットでも**VBAそのもの**で計算できます。台帳には触りません

- 値は、台帳にある実際の受注の値を借りたもの(13件)と、受注が1件も

## 台帳は要りません ── 書き出し1つで照合できる

珍しい仕様のロットは「来ないときは来ない」ので、**来た日に書き出して
もらうだけ**にしました。書き出しには受注の中身(板厚・板幅・製品単重・
梱包単位…)も画面の欄として入っていて、VBAはまさにその値で計算して
います。取り込みがそこから受注を組み立てるので、**台帳の写しを送って
もらう必要はありません**。

実物の7件で、台帳の写しを抜いて書き出しだけから組み立てても、
**7件すべて一致**しました(`tests/test_vba照合.py` が毎回確かめます)。

押し忘れが心配なら、計算Start のたびに**黙って**書き出すこともできます
(`CommandButton5_Click` の最後に `Call 照合_黙って書き出す` を1行。
知らせは一切出ません)。

## 1. 最初の1回だけ(2分)

1. 資材計算のブックで **Alt+F11**(VBE)
2. 前の版の「照合出力」モジュールを入れていたら、右クリック →
   **解放**(エクスポートは「いいえ」)。前の版は**見出しの行しか
   書けない不具合**がありました(`ctl.Object` で欄を読もうとして
   1欄目でエラーになっていた)
3. **挿入 → 標準モジュール**
4. [`docs/検証/照合出力.bas`](照合出力.bas) の中身を貼り付ける
5. 閉じる

保存が必要なら、いつもどおりブックを保存してください
（マクロ有効ブック `.xlsm` のままで構いません）。

## 2. 1件ごと(いつもの操作 ＋ 1回押すだけ)

| | すること |
| --- | --- |
| 1 | LotNo を入れる（表の LotNo） |
| 2 | 受注番号を選ぶ（候補が複数出るのは `L5160Z0` だけ） |
| 3 | 検入数を入れる（表の値） |
| 4 | **計算Start** |
| 5 | **Alt+F8 →「照合_この画面を書き出す」** |

これだけです。**断られた画面（「引当データなし」など）も、そのまま
押してください** ── 断ること自体が答え合わせの対象です。

外径は画面が入れた既定のままで構いません。打ち直したなら、その値も
一緒に書き出されるので、こちらはその値で計算します。

書き出し先はブックと同じフォルダの `照合_yyyymmdd.csv`（書けなければ
デスクトップ）。どこへ書いたか分からなくなったら
**「照合_保存先を表示する」**で出ます。

### 書き出されるものの見本

正しく動くと、1回押すごとに**画面の欄の数だけ行が増えます**
(1件あたりおよそ数十行)。形はこうです。

  いまの版に入れ替えてください
- **終わりに「○欄を書き出しました」と出る**ので、欄の数が0なら
  その時点で分かります(0のときは赤い×で知らせます)
- 1つの欄が読めなくても止まりません。その欄の値に
  `#読めず:(理由)` と書いて次へ進みます

## 3. 渡す

その CSV をそのまま渡してください。こちらで取り込みます。
自分で進めるなら:

```
python tools/照合取り込み.py 照合_20260922.csv
python -m pytest tests/test_vba照合.py -q
```

食い違うと、こう出ます。

```
L6052G0 が VBA と違います(VBA, こちら): {'積数': ('4', '3')}
```

**VBAが正で、移植が合わせます。**

## 4. なにが書き出されるか

画面のコントロールを端から読むので、**こちらが欄を決めていません**。
画面にあるものが、そのまま出ます。

- パレット種類・名称・サイズ／積数・台数・Re_積数・Re_台数・総高さ
- コイル間・リプラサイズ・最下部本数・最下部長さ・長い本数…
- 緩衝材・HB枚数・特殊Flag・PFlag
- **色も**（`F重量` `F枚数` `F高さ` `F包装仕様` の文字色が赤か、
  `FM` の枠が水色か赤か）── 目で見て書き写す必要はありません

色を取るのは、値がたまたま合っていても**決まり方が違う**ことが
あるためです（重量で決まったのか、高さで決まったのか）。

## 7. 使うデータについて

台帳は日々入れ替わるので、**同じ条件で二度と走らせられない**と
答え合わせになりません。この12件に要る行だけを
`tests/data/照合データ.sql` に凍らせてあります
（包装仕様12・パレット48・リプラサイズ8・仕掛引当13・仕掛受注13行）。

実在のロット番号・受注番号・取引先名が入っています。**納入先で分岐する
規則がある**ので伏せていませんが、伏せたほうがよければ言ってください。
