# はじめに読む — 起動と使い方

> **コイル梱包ツール(統合版)で使うとき**: 資材計算は「コイル梱包ツール」の **資材計算**タブの
> 中で動きます。起動・終了・ログ・書き出し先・配布設定の置き場所は、コイル梱包ツールのフォルダ
> (`Start.vbs` がある所)が基準です。この文書は統合版に合わせてあります。

## 起動する

**コイル梱包ツールのフォルダの `Start.vbs` をダブルクリックします。** これ1つだけです。
ブラウザが開いて、待機画面のあとにコイル梱包ツールの画面になります。上のタブの **資材計算** を選びます。

うまくいかないときは **`start.bat`** を使ってください。黒い画面に
原因が出ます(`Start.vbs` はコンソールを出さないので、何も起きない
ように見えます)。

止めるときは画面右上の **終了** を押すか、**`stop.bat`** を実行します(梱包明細・ペナラベルも一緒に止まります)。
画面を閉じただけでも、しばらくすると自動で終わります。

## 最初にすること

### 1. 取り込み元の置き場所を決める

左の **設定** を開きます。設定は上の見出し(**取り込み / マスタ管理 /
ラインと担当者 / 配布設定 / このアプリ**)で分かれているので、
**取り込み** の面を使います。

**置き場所を変えるにはパスワードが要ります**(マスタを直すのと同じ
ものです)。**設定のいちばん上**にパスワード欄があるので、そこで
認証してください ── どの面にいても同じ場所にあります。
置き場所を間違えると**その端末が計算できなくなる**ので、
担当者の選び直しとは別扱いにしてあります。

4つの欄があります。

| 欄 | 何を読む先か |
|---|---|
| 梱包資材マスタのフォルダ | 包装仕様・パレット・リプラサイズ |
| 仕掛台帳のフォルダ | ロット検索と受注情報 |
| 仕掛台帳の予備フォルダ | 本命が読めないときに見る先。**空でよい** |
| 書き出し先 | CSV を出す場所 |

打ったら、その欄の **確かめる** を押します。そこに届くか、目当ての
ファイルがあるかを見に行って、欄の下に結果が出ます。よければ
その欄の **この欄を保存**。

**保存は欄ごとです。** まとめて1つのボタンで書くと、直すつもりの
ない欄まで、そのとき画面に出ていた値で上書きしてしまいます。

**保存しただけでは手元のデータは変わりません。** 置き場所を直したら
**いま取り込む** を押してください。

**配布設定が置いてある場合は、ここは済んでいます。** コイル梱包ツールのフォルダの
`配布設定\packing_material_calculation` があれば、起動したときに置き場所などを読み込み
ます(下の「たくさんの端末に配るとき」)。

### 2. ラインと担当者を選ぶ

画面の上の帯で選びます(設定の **ラインと担当者** の面でも選べます)。
**選んだ時点で保存されます** ── 保存ボタンはありません。

- **ライン**(LS4 / NS1)… チェックリストの表題に出ます
- **担当者** … 発注票とチェックリストの依頼者欄に出ます。
  **梱包資材マスタの「班員名簿」のうち、担当ラインが「機側」の人**が
  出ます（班ごとに分かれています）。機側以外の人は出ません。
  人の出入りも担当ラインも、**日報ツール側の名簿**を直してください
  （ここでは直せません）。直したら「いま取り込む」を押します
  - 名簿に機側の人が1人も居ないときは、**絞らずに全員**出します
    （一覧が空だと誰も選べないため）。そのときは設定の担当者の下に
    「担当ラインが機側の人がいないので全員を出しています」と出ます

**担当者を選んでいないと、チェックリストへ積めません。**
誰が出したか分からない発注書が倉庫へ回らないようにするためです。

### たくさんの端末に配るとき(配布設定)

1台で置き場所などを決めたら、設定の **配布設定** の面で
**配布設定を書き出す** を押します(設定のいちばん上で認証してから)。
コイル梱包ツールのフォルダの **`配布設定\packing_material_calculation`** にできるので、
**コイル梱包ツールのフォルダごと**配ってください。

- 配った先は、**起動したときに読み込みます**
- その端末に**すでにある設定は上書きしません**(端末で直した値は戻らない)。
  揃え直したいときは、その端末で **配布設定を読み込み直す**
- 入れるものは面で選べます。**ラインは既定で入れません**(端末ごとに
  LS4 / NS1 が違う)。**担当者は入れられません**(人ごとに違う)
- この端末で変えていない項目は入りません(配った先も同じ既定で動くので)
- 管理者パスワードは撹拌した値で入ります(平文は入りません)

### このPCに残るもの・全ラインで共有するもの

設定の **「保存先（このPC／共有）」** の面に、実際のファイルの場所が出ます。各区画の見出しの札
(「このPCに保存」「全ラインで共有」「アプリのフォルダ」)でも分かります。

- **このPCに保存(このPCで引き継ぐ)**: 設定ファイル `user_config.json`(取り込み元の置き場所・ライン・
  担当者・自動取り込み・**パスワード**)と作業用DB `coil_tool.db`(取り込んだマスタと仕掛台帳の写し・
  チェックリスト・発注履歴)。閉じても、新しい版に入れ替えても残ります。**ほかのPCへは移りません**
- **全ラインで共有**: 梱包資材マスタ(「マスタ管理」で直すとここへ書くので、ほかのPCにも効きます)
- **パスワードはこのPCだけのものです。** 変えても、ほかのPCは変わりません。そろえるときは配布設定に入れて配ります

## ふだんの使い方

### 資材計算

1. **LotNo** を7桁打つと、受注番号の候補が出ます
2. **受注番号** を選ぶと、厚・幅・単重・包装仕様Noなどが展開されます
3. **検入数** を入れます(コイル外径は展開された値が入っていますが、
   打ち直せます)
4. **計算Start** を押します

**自分で打つ4つの欄**(LotNo・受注番号・検入数・コイル外径)は、
下の展開された値より**大きな字**にしてあります。打ち間違いにその場で
気づけるようにするためで、字が大きいほうが「打つ場所」です。

結果の欄に色が付くことがあります。**色は「どの規則で決まったか」**です。

| 見え方 | 意味 |
|---|---|
| 黄色い入力欄 | ここを入れないと計算できません |
| 見出しが赤くなる | その規則で決まりました(重量 / 枚数 / 高さ / 包装仕様) |
| 枠が水色・青 | 1本積み不可の品で、台数を分けました |

**積数を手で直せます。** 直すと台数だけを出し直します
(包装仕様No別の規則では上書きしません)。

リプラの本数は **最下部（パレットの上）** と **コイル間** の
2つの枠に分けてあります。どちらの本数かを取り違えないためです。
発注するのは枠の下に出る **ﾘﾌﾟﾗ総本数**（2つを足したもの）です。

最下部は **長 / 短** を列にした表で出ます。**1列を上から下に読めば
1組**です（長さと、その本数）。

|          |  長  |  短  |
|---|---|---|
| 長さ（mm） | 1200 | 1100 |
| 本数       |   21 |    0 |

### バリ揃え梱包

上向きのバリと下向きのバリを混ぜて積めない品で使います。
上下の本数を入れて **計算Start**、よければ **結果転送** で本体へ送ります。

本数は打ち込みのほか、欄の左右の **−** **＋** でも変えられます
(手袋のままでも押せます)。0より下へは行きません。
**押しただけでは計算しません** ── 数を決めてから **計算Start** です。

### チェックリスト

**包装仕様No を押すと**、番号をコピーして包装仕様書の閲覧システムが
別のタブで開きます。閲覧システムの検索欄に **Ctrl+V で貼り付け**て
ください(閲覧システムには番号が渡らないため)。

計算できたら **チェックリストへ積む** を押します。15行まで溜まります。
「ｻｲｽﾞ確定品」にチェックを入れると、左端に `〆` が付きます。

**印刷** はブラウザの印刷を使います(A4横・1ページ)。

### 発注票

チェックリストが溜まったら **発注票** の画面で **発注票を作る**。
リプラの角サイズごとに票ができます(30×40 / 40×60 / 80×80)。

倉庫の定尺(700 / 800 / 900 / 950 / 1000 / 1050 / 1100 / 1150)に
無い長さは、下の空欄に書き足されます。**5件以上あると作れません**
(票に入らないため)。

**印刷は A4 横1枚につき1票**です。票は紙の**左半分**に出て、真ん中に
**縦の切り取り線**（細い実線）が入っています。**そこで縦に切って**ください。
切ったあとの1枚は **A5 縦**（はがき2枚ぶんくらい）になります。

右半分は空白です。紙を節約するためではなく、**その大きさの票が
使いやすい**からこうしてあります。

票の体裁は、いま使っている原紙(`注文票.xlsx`)に合わせてあります。

- 上に「発注票」(枠なし)、その右に **提出日付 / 依頼者** の囲み枠
  (日付は `9/25` の形。依頼者が長い名前のときは字を小さくして枠に収めます)
- 1行目が **`ﾘﾌﾟﾗ` と 角サイズ**(太線で囲みます)。字はどれも細字です
- その下が明細12行(定尺8行 + 書き足し用4行)。**見出しの行はありません**
- 左から **長さ / LotNo / 数量 / 本**。原紙と同じく、LotNo と数量の
  あいだに縦線は入りません

印刷ダイアログで**用紙の向きが「横」**になっているか確かめてください。

同じ LotNo が **2週間以内** に発注されていると確認が出ます。
中身は先に見えるので、それを見てから続けるか決めてください。

出した内容は **発注済みとして記録** を押すまで履歴に残りません。

### マスタを直す

包装仕様・パレット・リプラサイズの中身は、**設定の「マスタ管理」**で
見られます。見るだけならそのままできます。
**見出し(列名)を押すと並べ替えます**(▲ 小さい順 / ▼ 大きい順。もう一度押すと逆。
数字は数の大きさで並び、空はいちばん後ろ)。

**直すにはパスワードが要ります。** **設定のいちばん上**の
パスワード欄に入れてください。入れると「+ 行を足す」が押せるように
なり、行を押すと直せる姿で開きます。
（同じパスワードで、取り込み元の置き場所も変えられるようになります）

直した内容は**共有フォルダの元のファイル**に書きます。
手元の写しではないので、**ほかの端末にも効きます**。
打ち間違えたまま保存すると全員に効くので、保存の前に一度読み直して
ください。

**30分さわらないと閉じます。** 席を立つときはそのままで構いませんが、
続きを直すときはもう一度パスワードを入れてください。

## 困ったとき

### 画面に「マスタ 古い」と出る

**取り込んだ日と今日が違う**ときに出ます。設定の **いま取り込む** を
押してください。マスタが更新されても、このツールは**自動では読み直し
ません**(計算の途中で足元の値が変わらないようにするためです)。

- 仕掛台帳は日ごとの台帳なので、**日付が変われば中身も変わります**。
  朝いちばんに1回押す、と覚えてください
- **夜勤で日付をまたいだとき**も出ます。「さっき取り込んだのに」と
  思ったら、札にカーソルを合わせると理由が出ます
  (「取り込んだ日から日付が変わりました」)

### 「そのロットに紐づく受注がありません」

仕掛台帳が取り込めていないか、そのロットがまだ台帳に無いかです。
設定の取り込み日時と、仕掛台帳のフォルダを確かめてください。

### 「引当データなし。計算ができません」

その受注に梱包単位(重量も枚数も)が入っていません。
オーダー側にデータが入るまで計算できません。

### 「収まるパレットがマスタにありません」

コイル外径に対して使えるパレットが、パレットマスタにありません。
外径の打ち間違いか、マスタの登録漏れです。

### 起動しない

コイル梱包ツールのフォルダの `start.bat` を実行すると原因が出ます。ログはここにあります。

    %LOCALAPPDATA%\CoilPackingTools\logs\

`coil_packing_tools_YYYYMMDD.log` に、起動の記録も業務の記録も入ります
(3機能で1つのファイル。資材計算の行は `coil_tool` で始まります)。

作業用のもの(DB・設定)は、すべて**その端末の中**にあります。

    %LOCALAPPDATA%\CoilMaterialTool\

端末ごとに別なので、チェックリストの途中や担当者の選択が
**ほかの端末と混ざることはありません**。

### 「すでに起動しています」と出る

**そのままで大丈夫です。** すでに開いているほうのブラウザが出ます
(アプリは1つだけ動く決まりになっています)。
うっかり2回押しても、2つ立ち上がることはありません。

画面が出てこないときだけ、`stop.bat` で止めてから起動し直してください。

### 「すでに別の画面で開いています」と出る

**このアプリは1つの画面でしか使えません。** タブを2枚開くと、
どちらで打った値が使われるのか分からなくなる(打った本人にも
見えない)ので、2枚目は開いた時点で断るようにしてあります。

- **もう一方のタブを探して、そちらを使ってください。**
  たいていは、閉じたつもりで残っているタブです
- もう一方が見つからない・使えない(ブラウザが固まった、別の人が
  開いたまま帰った)ときは、**「この画面で使う」**を押してください。
  もう一方は使えなくなります
- **「この画面で使う」を押すと、もう一方で入力の途中だったものは
  失われます。** 隣で誰かが使っていないか、先に確かめてください

もう一方のタブを閉じれば、この画面はそのまま使えるようになります
(閉じたことはすぐ伝わります)。

### 使っている途中で「この画面は使われなくなりました」と出た

別の画面で「この画面で使う」が押されました。**そちらの画面が
使える画面になっています。**

この画面で続けたいときは、もう一度「この画面で使う」を押して
ください。今度はもう一方が使えなくなります。

### 担当者の一覧に自分が出てこない

担当者は**梱包資材マスタの「班員名簿」**から出ています。

1. 設定の **ラインと担当者** の面を見てください。担当者欄の右に
   「班員名簿から ◯名」と出ていれば、名簿から読めています
2. 「内蔵の一覧を出しています」と出ていたら、名簿を取り込めて
   いません。**いま取り込む** を押してください
3. それでも出てこないときは、**日報ツール側の名簿**に登録が
   ありません。そちらへ登録してから、もう一度取り込んでください

### 版(バージョン)を聞かれたら

画面の**左上、アプリ名のとなり**に `VER0.1.0` のように出ています。
どの画面にいても出ています。

そこを押すと、設定の**「このアプリについて」**へ飛びます。
版のほかに、アプリID・ポート・Python・置き場所が出ているので、
問い合わせのときはこの画面を見ながら答えてください。

端末ごとにフォルダを写して配っているので、**端末によって版が違うこと
があります。** 「直ったはずなのに直っていない」ときは、まずここを
見比べてください。
