## 8. 未移植のもの（意図的）

| VBA | 理由 |
|---|---|
| `GetMyLineName` / `ExtractCommonLineName` / `SanitizeRegistryValue` | ライン名を**レジストリ**から取り、共有ログのフォルダ階層に使っていた。Web 版はログをユーザー別ローカル領域へ出すため階層分けが不要。ライン名が必要になった場合は `config/app.json` へ項目を追加する |
| `ListOen`（`日報＆資材計算.xlsm` を開く） | Excel ブックを開く処理。Excel の運用でだけ必要だった機能のため、本ツールでは削除した（現場確認 2026.09.25）。設定項目「日報ブックのファイル名」も削除 |
| `CommandButton6`（旧 重量計算） | 旧経路。最後が `DB_Materials(.CoilH4, 1)` となっており `CoilH1` を使うべきところが誤っている。現行の主経路 `CommandButton16` のみ移植 |
| `CommandButton3` / `CommandButton4`（シート表示/非表示） | Excel シートの可視性操作。Web には該当概念が無い |
| `CommandButton5`（フォーム切替） | 画面上部のナビゲーションで代替 |
| `FormSetting`（フォームのリサイズ可否） | Windows API。ブラウザーでは不要 |
| `印刷設定` / `風袋罫線設定` の罫線処理 | Excel の罫線描画。CSS で表現 |
| ADO 汎用ライブラリ（`adoSQL` `fldAccdb` `XlsToAccdb` 等） | 本システムは資材マスタの**読取のみ**。書込系は未使用 |
| ListView 汎用ライブラリ | UI 部品。HTML の table で代替 |
| `merge_sort2` / `配列比較差分取得` / `duplicateDelete` | 本システムから呼ばれていない |
| `Sleep` / `GetDC` / `CreateFont` / `DrawText` 等の Windows API | UI 描画用。不要 |

## 9. 画面ボタンとの対応（推定を含む）

`.frx`（フォームレイアウト）が提供されていないため、
スクリーンショットのキャプションと `CommandButtonN` の対応は **推定** を含む。

| スクリーンショットのキャプション | 推定される VBA | Web |
|---|---|---|
| 重量反映 | `CommandButton1` | 「重量反映」 |
| 小ラベル印刷 | `CommandButton2` | 「小ラベル印刷」 |
| 重量計算_DB | `CommandButton16` | 「重量計算_DB」 |
| 重量計算 | `CommandButton6` | （旧経路のため未移植） |
| 計算内容表示 | `CommandButton7` | 「計算内訳（表記用）」 |
| 風袋計算内容印刷 | `CommandButton10` | 「風袋計算内容印刷」 |
| 日報 | `CommandButton14`（`ListOen`） | 削除（Excel でだけ必要。設定項目・画面の注記も削除） |
| 直接選択モード | ラベル/モード表示 | 「まとめてやりたい場合チェックon」の反対側 |

対応が誤っている場合は `app/templates/index.html` のボタン配置を調整すればよい
（業務ロジックには影響しない）。
