# 変更履歴(ペナラベル)

版は `app/config.py` の `APP_VERSION` ただ1つが出どころです(移植元のまま。
`config/app.json` には書きません)。

**統合版(コイル梱包ツール)では版が2つあります。** この機能の版(ここ)と、
統合ツールの版(統合アプリの `config/app.json`)です。この機能の中身(画面・計算・
印刷・DB)を変えたら**この機能の版を上げ、統合ツールの版も上げます**(配る単位は
統合ツールのため)。画面の帯の版を押すと、両方の版が並んで出ます。

## 版の上げ方

1. `app/config.py` の `APP_VERSION` を上げる
2. このファイルに1行足す(何を直したか)
3. 統合ツールの版(統合アプリの `config/app.json`)も上げる

## 統合版への組み込み(コイル梱包ツール 1.0.0 に同梱) — 版は 1.5.0 のまま

移植元 `ViVio-Hellon/packing-pena-label-python-web` の v1.5.0 を、コイル梱包ツールの
「ペナラベル」タブとして組み込みました。**計算・入力チェック・状態DB・ラベルと印刷ビューの
紙面は変えていません。** 統合のために変えたところ:

- http.server の代わりに統合アプリ(Flask)の中で動きます。画面と API のクラスはそのまま
- 経路の前に `/pena` が付きます(画面・API・印刷ビュー・フォント)
- API に起動トークンが要ります(同じプロセスに同居する他の2機能と揃えた。画面の JS が付けます)
- 移植元は自動では止まりませんでした。統合版は画面が全部居なくなると止まりますが、
  **印刷ビューを開いた別のタブがあるあいだは止まりません**(移植元の「使っている間は
  止まらない」を守る)
- ログは統合アプリの1つのファイルに入ります
- 配布設定は統合アプリの直下の `配布設定\packing_pena_label\`(梱包明細・資材計算と同じ決まり)。
  配布用フォルダを作ると、3機能の配布設定をまとめて入れます
- 起動・停止・多重起動の判定・配布用フォルダの作成は統合アプリのもの(`Start.vbs` `stop.bat`
  `scripts\make_dist.py`)
- 統合画面で Ctrl+P を押すと、この画面が刷られます(外枠は刷られません)。
  「このまま印刷」「試し刷り」はこれまでどおり、この画面だけを刷ります
