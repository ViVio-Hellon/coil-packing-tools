# assets フォルダ

処理の材料となる固定資産を置く（基盤仕様書 4.4）。

| 想定する中身 | 用途 |
|---|---|
| ラベル台紙テンプレート | 印刷レイアウトの原本。現行は HTML/CSS で表現しているため未使用 |
| 空の Access DB | `梱包資材マスタ.accdb` の雛形が必要になった場合 |
| 帳票の雛形 | 風袋計算・羅列計算の様式を差し替える場合 |

`config`（設定）・`data`（マスタ）と分けているのは、
更新時に「何を保持して何を置き換えるか」を判断しやすくするため。

現時点では空。台紙レイアウトを Excel から差し替える運用になった場合にここへ置く。
