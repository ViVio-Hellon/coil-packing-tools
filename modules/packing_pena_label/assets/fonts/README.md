# バーコードフォント

Excel 台紙は **K's BarCodeFont Code39** で `*...*` をバーコードとして表示していた。

## 2 通りの出し方

| モード | 設定 `barcode_mode` | 内容 |
|---|---|---|
| **SVG（既定）** | `svg` | Code 39 を**自前でバー描画**する。フォント不要 |
| フォント | `font` | ここに置いた TTF を使い、**現行と同じ字形**で出す |

既定が SVG なのは、ライン PC のブラウザーに同じフォントがある保証がなく、
フォント未導入だと**バーコードではなくただの文字列が印刷されてしまう**ため。

現行の読取機での実績を優先したい場合は `font` へ切り替える。

## 置くファイル

| ファイル | font-family |
|---|---|
| `KsBarCodeCode39.ttf` | `K's BarCodeFont Code39` |
| `Code39Barcode.ttf` | `Code39` |

`/settings` の「ラベル印刷」→ バーコードの出し方 / バーコードフォント名 で選ぶ。

## 配布時の注意

**これらは第三者のフォントであり、再配布の可否はライセンス次第。**
`.gitignore` で `*.ttf` を除外しているため、リポジトリには入らない。
配布物へ同梱する場合は、フォントの配布条件を確認すること。
確認が取れない場合は、既定の SVG モードのまま運用すれば**フォントは不要**。
