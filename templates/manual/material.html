{% endblock %} {% block body %} {{ m.heading("資材計算") }}

ロットから、パレット・リプラ・緩衝材の員数を出し、チェックリストに積んで発注票を作ります(コイル梱包資材計算ツール)。 統合画面の {{ m.b('資材計算') }} タブで使います。写真は試験用のデータです(名前・番号は作り物です)。

1画面の見方

{{ m.fig("material-start", "資材計算を開いたところ。上の帯で担当者を選んでから使います。") }}
  1. {{ m.n(1) }}版({{ m.b('VER' ~ versions.material) }}):押すと 設定 →「このアプリ」が開きます(版を確かめる)。
  2. {{ m.n(2) }}マスタ:取り込んだ日時。「古い」と出たら取り込みをします(朝いちばんに1回)。
  3. {{ m.n(3) }}ライン:LS4 / NS1。変えるとすぐ覚えます(チェックリストの表題に出ます)。
  4. {{ m.n(4) }}担当者:自分の名前を選びます。選んでいないとチェックリストに積めません。
  5. {{ m.n(5) }}左のメニュー:{{ m.b('資材計算') }} {{ m.b('チェックリスト') }} {{ m.b('発注票') }} {{ m.b('設定') }}。

2資材の員数を出す

{{ m.fig("material-input", "ロット番号を入れると受注の情報が出ます。検入数と外径を入れて「計算Start」を押します。") }}
  1. {{ m.n(1) }}LotNo(7桁)を入れます。7桁そろうと自動で探し、受注の情報(厚・幅・材質・包装仕様No…)が出ます。
  2. {{ m.n(2) }}受注番号:候補が1つなら自動で選ばれます。2つ以上あれば選びます。
  3. {{ m.n(3) }}検入数(本)を入れます。
  4. {{ m.n(4) }}コイル外径(mm)を確かめます(黄色の欄は入れる欄です)。
  5. {{ m.n(5) }}{{ m.b('計算Start') }} を押します。「台数 N 台 / ﾘﾌﾟﾗ N 本」と出ます。
{{ m.fig("material-result", "計算結果。パレットの種類・台数・リプラの長さと本数などが出ます。") }}
  1. {{ m.n(1) }}パレット種類・サイズ・名称。
  2. {{ m.n(2) }}台数。積数(本/台)は手で直せます。その下に、コイル間・ﾘﾌﾟﾗｻｲｽﾞ・緩衝材と、最下部(パレットの上)とコイル間のリプラの長さ・本数が出ます。
見方決め手になった規則の見出しは赤字に●が付きます。1本積みができず台数を分けたときは、値が青い枠で囲まれます。{{ m.b('単重再計算') }} は外径・内径・幅・比重から単重を計算し直します。{{ m.b('はじめから') }} で入力を消します。
{{ m.fig("material-spec", "包装仕様No を押すと、番号をコピーして閲覧システムを開きます。") }}
  1. {{ m.n(1) }}包装仕様No(青い下線の文字)を押すと、番号をコピーして閲覧システム(社内のサイト)を開きます。デスクトップ版では、いつものブラウザで開きます。開いた画面の検索欄に貼り付けて(Ctrl+V)探します。

3チェックリストへ積む

{{ m.fig("material-add", "計算結果の下。リプラの総本数を確かめて「チェックリストへ積む」を押します。") }}
  1. {{ m.n(1) }}ﾘﾌﾟﾗ総本数を確かめます。
  2. {{ m.n(2) }}サイズが確定している品物なら {{ m.b('ｻｲｽﾞ確定品') }} にチェックを入れます(チェックリストの「確定」欄に「〆」が付きます)。
  3. {{ m.n(3) }}{{ m.b('チェックリストへ積む') }} を押します。「チェックリストの 1 行目に積みました」と出ます。15行まで積めます。

4チェックリスト

{{ m.fig("material-checklist", "左のメニューの「チェックリスト」。積んだ行が並びます。") }}
  1. {{ m.n(1) }}積んだ行です。いらない行は右端の {{ m.b('消す') }} で消します。
  2. {{ m.n(2) }}{{ m.b('印刷') }}:チェックリストの紙面を別の窓(ブラウザ版では別のタブ)で開きます。
  3. {{ m.n(3) }}{{ m.b('発注票へ') }}:発注票の画面へ移ります。
  4. {{ m.n(4) }}{{ m.b('全部消す') }}:チェックリストを空にします(確かめが出ます)。
{{ m.fig("material-checklist-print", "チェックリストの紙面(A4横)。") }}
  1. {{ m.n(1) }}{{ m.b('印刷する') }} で印刷の窓が開きます(Ctrl+P と同じ)。倍率は100%のままにします。ボタンと案内は紙には出ません。

5発注票

{{ m.fig("material-order", "左のメニューの「発注票」。チェックリストから、リプラの角サイズごとに票を作ります。") }}
  1. {{ m.n(1) }}{{ m.b('発注票を作る') }} を押します。「N 枚作りました」と出ます。
  2. {{ m.n(2) }}{{ m.b('印刷') }}:発注票の紙面を開きます。
  3. {{ m.n(3) }}{{ m.b('発注済みとして記録') }}:刷って出したら押します(確かめが出ます)。記録した発注は、2週間以内の同じロットの重複を見つけるのに使います。
  4. {{ m.n(4) }}作った票です(長さ・LotNo・数量)。
{{ m.fig("material-order-print", "発注票の紙面。A4横の左半分に1票。真ん中で切るとA5縦になります。") }}
  1. {{ m.n(1) }}{{ m.b('印刷する') }} で印刷の窓が開きます。
注意「2週間以内に発注あり」と出たら、同じロットをもう発注しています。中身を見て、重複してよければ {{ m.b('このまま作る') }}、やめるなら {{ m.b('やめる') }}。

6バリ揃え梱包

資材計算の画面のいちばん下「3. バリ揃え梱包」は、上向きと下向きのバリを混ぜて積めない品のときに使います。 {{ m.b('上バリ（本）') }} {{ m.b('下バリ（本）') }} を {{ m.b('−') }} {{ m.b('＋') }} で入れて {{ m.b('計算Start') }} を押すと、上台数・下台数・台数が出ます。{{ m.b('結果転送') }} で台数を計算結果へ送ります。

7設定・取り込み

{{ m.fig("material-settings", "左のメニューの「設定」。いちばん上が直すための認証、その下がタブです。") }}
  1. {{ m.n(1) }}直すための認証:置き場所・マスタ・配布設定を直すときだけ、パスワードを入れて {{ m.b('認証する') }}。見るだけなら要りません(「見るだけ」と出ています)。30分さわらないと自動で閉じます。
  2. {{ m.n(2) }}タブ:{{ m.b('取り込み') }} {{ m.b('マスタ管理') }} {{ m.b('ラインと担当者') }} {{ m.b('配布設定') }} {{ m.b('保存先（このPC／共有）') }} {{ m.b('このアプリ') }}。
  3. {{ m.n(3) }}取り込み元の置き場所:欄ごとに {{ m.b('確かめる') }} で届くか見てから {{ m.b('この欄を保存') }}。置き場所を直したあとは「いま取り込む」を押します。
{{ m.fig("material-import", "取り込みの区画。") }}
  1. {{ m.n(1) }}起動したときに自動で取り込む:チェックを入れておくと、起動のたびに取り込みます(待機画面に進み具合が出ます)。
  2. {{ m.n(2) }}{{ m.b('いま取り込む') }}:すぐ取り込みます。終わるまで「取り込んでいます…」になります。終わると件数が出ます。
  3. {{ m.n(3) }}表ごとの取り込み日時と件数。「未取り込み」があれば取り込みます。
{{ m.fig("material-team", "「ラインと担当者」。") }}
  1. {{ m.n(1) }}ライン:選ぶとすぐ保存されます(上の帯の欄と同じです)。
  2. {{ m.n(2) }}担当者:梱包資材マスタの「班員名簿」の、担当ラインが機側の人が出ます。名前が無いときは取り込みをします。

8マスタ管理(包装仕様・パレット・リプラサイズを直す)

{{ m.fig("material-master", "「マスタ管理」。認証すると「直せます」になります。") }}
  1. {{ m.n(1) }}直せます/見るだけ:認証していないと「見るだけ」です。直すときは先にいちばん上で認証します。
  2. {{ m.n(2) }}表の一覧:見たい表を押します。直せるのは 包装仕様・パレット・リプラサイズ の3つです。
  3. {{ m.n(3) }}絞り込み:どの列の文字でも探せます(例:1C1188 / スカシ / リプラ)。{{ m.b('+ 行を足す') }} で行を足せます。
  4. {{ m.n(4) }}見出しを押すと並べ替わります(▲小さい順/▼大きい順)。行を押すと、その1行の窓が開きます。
{{ m.fig("material-master-row", "1行の窓。直して「取り込み元へ書く」を押します。") }}
  1. {{ m.n(1) }}{{ m.b('取り込み元へ書く') }}:手元の写しではなく元の梱包資材マスタ(全ラインで共有)を直します。ほかのラインにも効きます。行を消すときは {{ m.b('× この行を消す') }}(戻せません)。
注意「マスタを直すにはパスワードが要ります」と出るときは、認証していません(見るだけの状態)。班員名簿など、このツールで直さない表は「見るだけ」のままです(日報ツールなど、持ち主の側で直します)。

9版を確かめる

{{ m.fig("material-about", "設定 →「このアプリ」。") }}
  1. {{ m.n(1) }}資材計算の版(いまは VER{{ versions.material }})。その下に、置き場所(アプリ本体・作業用DB・ログ)が出ます。問い合わせのときに伝えてください。

10困ったとき

出たもの・起きたことすること
そのロットに紐づく受注がありません台帳を取り込めていないか、まだ台帳にないロットです。設定の {{ m.b('いま取り込む') }} をして、もう一度入れます。
検入数を入力してください検入数を入れてから {{ m.b('計算Start') }}。
引当データなし。計算ができません受注に梱包単位(重量・枚数)がありません。オーダーの側のデータを待ちます。
包装仕様No … がマスタに登録されていません梱包資材マスタに無い包装仕様です。マスタの担当に伝えます。
外径 … が収まる「…」のパレットがマスタにありません外径の打ち間違いか、マスタの登録漏れです。外径を確かめます。
担当者を選んでください(帯の担当者欄)上の帯の担当者で自分の名前を選びます。
チェックリストが15行埋まっています発注票を作るか、いらない行を消します。
先に発注票を作ってください{{ m.b('発注票を作る') }} を押してから記録します。
帯に「古い」設定の {{ m.b('いま取り込む') }} を押します。
すでに別の画面で開いています資材計算は1つの画面でしか使えません。もう一方を使うか {{ m.b('この画面で使う') }}(もう一方の入力の途中は消えます)。
エラー番号 E…番号を伝えてください。統合画面の {{ m.b('ログ') }} で中身を見られます。
