テスラ向けの出荷ラベル(小ラベル)を刷り、梱包の風袋・NW・GW・高さを計算します(梱包ペナ ラベル・風袋計算)。 統合画面の {{ m.b('ペナラベル') }} タブで使います。写真は試験用のデータです(右上の札が「CSV（検証用）」になっているのは試験用の資材マスタのためです)。

1画面の見方

{{ m.fig("pena-start", "ペナラベルを開いたところ(指定サイズの画面)。") }}
  1. {{ m.n(1) }}上のメニュー:{{ m.b('指定サイズ') }}(ふだんの画面) {{ m.b('風袋計算') }} {{ m.b('計算内容') }} {{ m.b('ラベル台紙') }} {{ m.b('全サイズ') }} {{ m.b('設定') }}。
  2. {{ m.n(2) }}版(v{{ versions.pena }} と、版を切った日)。画面の下の帯にも出ています。
  3. {{ m.n(3) }}接続OK:動いている印です。左の札は、資材マスタをどこから読んでいるか(SQLite・Access(ACE)・CSV)です。赤い「(古い内容)」が付いたら、資材マスタを読み直せていません。

2小ラベルを刷る(毎日の作業)

手順1 サイズを選んで重量を反映する

{{ m.fig("pena-weight", "サイズを選び、新しい検番と重量を入れて「重量反映」を押します。") }}
  1. {{ m.n(1) }}丈1と丈2をまとめてやるときは「まとめてやりたい場合チェックon(丈1・丈2 同時)」にチェックを入れます。片方だけなら外したままです。
  2. {{ m.n(2) }}サイズを選びます(0.8mm×53.5mm か 1.0mm×53.5mm。チェックを入れていれば「丈1・丈2 同時」、外していれば「丈1」か「丈2」)。選ぶと、その台紙の前の検番・重量が「現状値」に出ます。
  3. {{ m.n(3) }}新検番:英字1文字+数字6桁の7桁(例:W111111)。小文字は大文字に直ります。
  4. {{ m.n(4) }}新重量 丈1を入れます。
  5. {{ m.n(5) }}新重量 丈2を入れます(選んでいない丈の欄は薄くなって入れられません)。
  6. {{ m.n(6) }}{{ m.b('重量反映') }} を押します。「重量を反映しました」と出て、「現状値」が新しい値になります。

手順2 重量計算_DB(NW・GW・高さ)

{{ m.fig("pena-tare", "積み本数を入れて「重量計算_DB」を押すと、NW・GW・高さが出ます。") }}
  1. {{ m.n(1) }}チップボールサイズ(1000 / 950 / 820)を選びます。
  2. {{ m.n(2) }}積み本数を、丈ごとに 1梱包目・2梱包目 入れます。
  3. {{ m.n(3) }}{{ m.b('重量計算_DB') }} を押します。資材マスタを確かめてから計算し、「計算しました」と出ます。
  4. {{ m.n(4) }}NW・GW・高さ(mm)が出ます。
  5. {{ m.n(5) }}{{ m.b('小ラベル印刷') }} を押します。「…を印刷しますか？」に {{ m.b('OK') }} で、ラベルの紙面が別の窓(ブラウザ版では別のタブ)で開きます。
注意重量や本数を変えたら、必ずもう一度 {{ m.b('重量計算_DB') }} を押します。押さないまま刷ろうとすると「入力が変わっています。印刷を止めています。」と出て、刷れません(古い値のラベルを出さないため)。

手順3 ラベルを刷る

{{ m.fig("pena-labels-print", "小ラベルの紙面(実寸)。1台紙で16枚。上の帯の「印刷する」で刷ります。") }}
  1. {{ m.n(1) }}{{ m.b('印刷する') }} を押します。印刷の窓は何も変えずにそのまま「印刷」で大丈夫です(倍率「実際のサイズ」・余白「なし」が最初から選ばれています)。

刷り終えたら、上の帯の {{ m.b('このタブを閉じる') }} で閉じます。{{ m.b('積み高さ計算') }} は参考の高さを出すだけで、帳票には出ません。{{ m.b('クリア') }} は NW・GW・高さと本数欄を消します。

3風袋計算を見る・刷る

{{ m.fig("pena-tare-view", "上のメニューの「風袋計算」。梱包ごとの資材の重さと式が見られます。") }}
  1. {{ m.n(1) }}上のメニューの {{ m.b('風袋計算') }} を押します。
  2. {{ m.n(2) }}{{ m.b('印刷ビューを開く') }} を押すと、印刷用の画面が開き、すぐ印刷の窓が出ます。
{{ m.fig("pena-tare-print", "風袋計算の印刷用の画面。") }}

{{ m.b('計算内容') }} では梱包ごとの資材・重量・計算式を、{{ m.b('ラベル台紙') }} では14枚の台紙の一覧と、それぞれの {{ m.b('表示') }} {{ m.b('印刷') }} が見られます。戻るときは {{ m.b('指定サイズ') }}。

4全サイズ

{{ m.fig("pena-allsize", "上のメニューの「全サイズ」。型番マスタのサイズを選んで、まとめてラベルを作ります。") }}
  1. {{ m.n(1) }}サイズ選択(型番マスタ)を選びます。台紙が用意されて画面が読み直されます。
  2. {{ m.n(2) }}検番を入れます。
  3. {{ m.n(3) }}コイル副番の {{ m.b('2ケタ') }}(例 1-1)か {{ m.b('3ケタ') }}(例 2-2-1)を選びます。
  4. {{ m.n(4) }}重量を入れます(3ケタのときは欄が増えます)。
  5. {{ m.n(5) }}{{ m.b('決定') }} を押すと「反映値」に結果が出ます。
  6. {{ m.n(6) }}{{ m.b('印刷') }} を押すと、印刷用の画面が開きます。
{{ m.fig("pena-allsize-print", "全サイズの印刷用の画面。") }}

5印刷の位置合わせ(プリンターごとに一度)

ラベルが台紙の枠からずれて刷られるときに、一度だけ合わせます。合わせた値はこのPCに覚え、次からずっと効きます。

{{ m.fig("pena-labels-print-note", "小ラベルの紙面の上の案内。「位置合わせ（試し刷り）」から合わせます。") }}
  1. {{ m.n(1) }}ふだんはここで {{ m.b('印刷する') }} を押すだけです。
  2. {{ m.n(2) }}ずれるときは {{ m.b('位置合わせ（試し刷り）') }} を押します。
{{ m.fig("pena-calibration", "位置合わせの画面。まず普通紙に試し刷りします。") }}
  1. {{ m.n(1) }}{{ m.b('試し刷り') }} を押して、普通紙に1枚刷ります(印刷の窓は何も変えません)。刷った紙を台紙と重ね、点線の枠がラベルの切れ目から、どっちへ何mmずれているかを定規で測ります。
  2. {{ m.n(2) }}終わったら {{ m.b('ラベル印刷へ戻る') }} で戻ります。
{{ m.fig("pena-calibration-fix", "「ずれを直す」。測った向きと量を入れて「直す」を押します。") }}
  1. {{ m.n(1) }}横のずれの向き({{ m.b('左') }}/{{ m.b('右') }})を選びます。
  2. {{ m.n(2) }}横にずれている量(mm)を入れます。
  3. {{ m.n(3) }}縦のずれの向き({{ m.b('上') }}/{{ m.b('下') }})を選びます。
  4. {{ m.n(4) }}縦にずれている量(mm)を入れます。ずれていない向きは 0 のままで構いません。
  5. {{ m.n(5) }}{{ m.b('直す') }} を押します。入れた量だけ逆に動かして刷るようになります。もう一度試し刷りして確かめます。
コツ少しだけ残ったら「少しずつ動かす」の {{ m.b('↑ 上へ') }} {{ m.b('← 左へ') }} {{ m.b('右へ →') }} {{ m.b('↓ 下へ') }} で詰めます。下の段ほどずれが大きいときは「大きさそのものが合わないとき」を開きます。元に戻すときは {{ m.b('最初（ずらさない）に戻す') }}。

6設定

{{ m.fig("pena-settings", "上のメニューの「設定」。") }}
  1. {{ m.n(1) }}合言葉:フォルダやファイルの場所を変える・マスタを書き換える・配布設定を扱うときだけ要ります(印刷の位置合わせには要りません)。
  2. {{ m.n(2) }}{{ m.b('パス設定') }}:資材マスタの参照先・ラベル台紙・帳票の保存先など。変えたら {{ m.b('保存する') }}。{{ m.b('資材マスタへの接続を試す') }} で、保存せずに読めるか試せます。
  3. {{ m.n(3) }}{{ m.b('マスタ管理') }}:資材マスタ(SQLite)の中身を見る・直す。
  4. {{ m.n(4) }}{{ m.b('配布設定') }}:この端末の設定を、ほかのPCに配る形で書き出します。
{{ m.fig("pena-settings-storage", "「設定の保存先（このPC／複数のPCで共有）」。") }}

このPCに保存のもの(この端末の設定・印刷位置の補正・作業の状態)はこのPCだけで使います。全ラインで共有のもの(資材マスタ)を変えると、ほかのラインにも効きます。

資材マスタは、SQLite → Access(ACE)→ 同梱の CSV の順に読める物を使います。どれを読んだかは右上の札に出ます。

7版を確かめる

ペナラベルの版は、画面の左上の「v{{ versions.pena }}」と、画面の下の帯に出ています。下の帯の {{ m.b('診断') }} を押すと、版・版を切った日・資材マスタをどこから読んだかなどがまとめて出ます。問い合わせのときに伝えてください。
