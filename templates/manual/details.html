ロットを開いて重量を入れ、積む順にコイルを押して梱包明細表を出します(コイル梱包明細打ち出しシステム)。 統合画面の {{ m.b('梱包明細') }} タブで使います。写真は試験用のデータです。

1画面の見方

{{ m.fig("details-start", "梱包明細を開いたところ。まずロット番号を入れます。") }}
  1. {{ m.n(1) }}ロット番号:7桁を入れると自動で探します。
  2. {{ m.n(2) }}{{ m.b('取り込み') }}:仕掛台帳を最新にします(台帳を取り込む)。右には取り込んだ日時が出ています。
  3. {{ m.n(3) }}{{ m.b('履歴') }}:前に出した明細表を探して、紙面を作り直します(履歴から作り直す)。
  4. {{ m.n(4) }}{{ m.b('設定') }}:台帳の置き場所・紙面の右上の文字など(設定)。
  5. {{ m.n(5) }}版({{ m.b('VER ' ~ versions.details) }}):押すと「バージョン情報」が出ます(版を確かめる)。

{{ m.b('マスタ管理') }} では梱包資材マスタ・明細の履歴の中身を見られます(見るだけ。直せません)。

見出しの {{ m.b('説明書') }} は、梱包明細の文字だけの詳しい説明書(取り込み元・ファイルの置き場所など、管理する人向けのことまで)を開きます。 文字だけの詳しい説明書を開く

2明細表を出す(毎日の作業)

手順1 ロットを開く

{{ m.fig("details-lot", "ロット番号を7桁入れたところ。割数・受注・包装仕様NO・ロットの情報が出ます。") }}
  1. {{ m.n(1) }}ロット番号に7桁を入れます。小文字は大文字に直ります。7桁そろうと自動で探します。
  2. {{ m.n(2) }}割数(例:縦割2 × 横割12)と前工程実績数が自動で入ります。違うときは {{ m.b('修正する') }} で直せます。
  3. {{ m.n(3) }}用途・材質・板厚・板幅などロットの情報が出ます。合っているか確かめます。
コツ同じロットを前に途中までやっていたときは、「前回の条番号情報を復元しました」と出て、続きから始まります。

手順2 重量を入れる

{{ m.fig("details-weights", "丈数と、丈ごとの重量を入れて「条番号表示」を押します。") }}
  1. {{ m.n(1) }}丈数:ふつうは自動で入ります(縦割数)。{{ m.b('−') }} {{ m.b('＋') }} で直せます。
  2. {{ m.n(2) }}丈ごとの重量を整数で入れます。下の {{ m.b('-10') }} {{ m.b('-1') }} {{ m.b('+1') }} {{ m.b('+10') }} でも増減できます。
  3. {{ m.n(3) }}{{ m.b('条番号表示') }} を押します。条番号と積み上げの欄が出ます。

{{ m.b('反転') }} は条番号の並びを左右逆にします。{{ m.b('廃棄選択') }} を押している間は、押したコイルに廃棄の印(×)を付け外しできます。

手順3 積む順にコイルを押す

{{ m.fig("details-stack", "積み条数を決めて、積む順にコイルを押しているところ。右の積み上げは下から埋まります。") }}
  1. {{ m.n(1) }}積み条数(1〜15)を入れます。右に同じ数の枠ができます。
  2. {{ m.n(2) }}条番号のコイルを、積む順に押します。押したコイルは色が変わります。
  3. {{ m.n(3) }}積み上げに下から入ります(下がスロット1=最初に積むもの)。間違えたら、積み上げの枠を押すと外せます。

手順4 出力する

{{ m.fig("details-ready", "積み上げが全部埋まると「出力」が押せるようになります。") }}
  1. {{ m.n(1) }}積み上げの枠が全部埋まったか確かめます。
  2. {{ m.n(2) }}{{ m.b('出力') }} を押します。すでに出力した副番が入っているときは確かめの窓が出ます(確かめの窓)。
{{ m.fig("details-output", "出力したところ。「出力済み」に1枚増えます。") }}
  1. {{ m.n(1) }}「出力しました。No1を確認してください。」と出ます。
  2. {{ m.n(2) }}出力済みに「ロット番号-No」が並びます。積み上げは空に戻り、使ったコイルは「使用済み」の色になります。
  3. {{ m.n(3) }}{{ m.b('印刷') }} を押すと、紙面が別の窓(ブラウザ版では別のタブ)で開きます(紙に刷る)。

3紙に刷る

{{ m.fig("details-report", "明細表の紙面。点線の欄にサイズ・LOTNOを書き足せます。") }}
  1. {{ m.n(1) }}点線の欄を押すと、サイズ・LOTNO を書き足せます(紙面の「寸法」「検番」の行)。打って Enter で「保存しました」と出ます。空のままなら何も刷りません。
  2. {{ m.n(2) }}{{ m.b('印刷する') }} を押すと印刷の窓が開きます(Ctrl+P と同じ)。
注意印刷の窓では 用紙 A4横・余白なし・倍率100% のままにします。明細表は用紙の左半分に出ます(右半分は空白)。ボタンや案内の文字は紙には出ません。

4まとめて刷る・No指定・副番履歴クリア

  • まとめて刷る:「出力済み」のチェックを入れて {{ m.b('印刷 (N枚)') }} を押します。1枚ずつ別の用紙に、Noの順に出ます。
  • No指定:刷り直しなどで番号を決めて出すときは、{{ m.b('No指定') }} にチェックを入れて番号を入れ、{{ m.b('出力') }} を押します。
  • 副番履歴クリア:{{ m.b('副番履歴クリア') }} で、出力済みの副番の記録を消します(連番は戻りません)。

5台帳を取り込む

  1. {{ m.n(1) }}{{ m.b('取り込み') }} を押します。「取り込み中」の窓に進み具合が出ます。終わると自動で閉じます。
  2. {{ m.n(2) }}取り込んだ件数が出て、右上の日時が新しくなります。
コツ「仕掛台帳がまだ取り込まれていません」と出たときや、ロットが見つからないときは、まず取り込みをします。開いていたロットは、ロット番号を入れ直すと新しい台帳で引き直します。

6履歴から紙面を作り直す

全ラインで出した明細表の記録(3年ぶん)から探して、紙面を作り直せます。

{{ m.fig("details-history", "「履歴」を押したところ。期間やロット番号で探して、選んだ紙面を開きます。") }}
  1. {{ m.n(1) }}出力日の範囲を入れます(最初は今月1日〜今日)。ロット番号(前方一致)や副番でも絞れます。
  2. {{ m.n(2) }}{{ m.b('探す') }} を押します。
  3. {{ m.n(3) }}作り直したい行を押して選びます(もう一度押すと外れます)。
  4. {{ m.n(4) }}{{ m.b('選んだ紙面を開く') }} を押します(一度に20枚まで)。「履歴から作り直した紙面です(書き足しはできません)」と出る紙面が開きます。

7設定

{{ m.fig("details-settings", "「設定」を押したところ。上のタブで中身を切り替えます。") }}
  1. {{ m.n(1) }}{{ m.b('置き場所・取り込み') }}:仕掛台帳・梱包課共有の仕掛・CSVの出力先・共有のフォルダの場所。欄ごとに保存します。
  2. {{ m.n(2) }}{{ m.b('紙面の右上の文字') }}:明細表の右上に赤く刷る文字(全ラインで共有)。
  3. {{ m.n(3) }}{{ m.b('管理者パスワード') }}:右上の文字・共有の場所を変えるためのパスワード(全ラインで共有)。
  4. {{ m.n(4) }}{{ m.b('配布設定') }}:この端末の設定を、ほかのPCに配る形で書き出します。
  5. {{ m.n(5) }}{{ m.b('保存先（このPC／共有）') }}:設定やデータがどこに保存されているか。

紙面の右上の文字を変える

{{ m.fig("details-settings-qa", "「紙面の右上の文字」。変えると全ラインの紙面が変わります。") }}
  1. {{ m.n(1) }}いま刷る文字と、どこから読んだか(梱包資材マスタ・控えのJSON・既定)が出ています。
  2. {{ m.n(2) }}新しい文字を入れます(20文字まで)。
  3. {{ m.n(3) }}管理者パスワードを入れます。
  4. {{ m.n(4) }}{{ m.b('保存') }} を押します。全ラインで、次に開く紙面から効きます。元に戻すときは {{ m.b('既定に戻す') }}。

保存先(このPC/共有)

{{ m.fig("details-settings-store", "「保存先（このPC／共有）」。このPCだけのものと、全ラインで共有しているものが分かります。") }}

このPCに保存のもの(設定・手元のDB・ログ)はこのPCだけで使います。全ラインで共有のもの(梱包資材マスタ・明細の履歴・管理者パスワード)を変えると、ほかのラインにも効きます。

8版を確かめる

{{ m.fig("details-about", "見出しの版を押したところ(バージョン情報)。") }}
  1. {{ m.n(1) }}梱包明細の版(いまは VER {{ versions.details }})。その下に、実行フォルダ・手元のDB・ログの場所・台帳を取り込んだ日時が出ます。問い合わせのときに伝えてください。

9よく出る確かめの窓

出る文意味と押すボタン
前回の出力(…)がまだ印刷されていません。シートを削除してよいですか？出力したのに印刷していないまま、別のロットを開こうとしました。印刷が済んでいれば {{ m.b('はい') }}。まだなら {{ m.b('いいえ') }} で戻って印刷します。
以下の副番はすでに出力済みです。このまま出力しますか？同じコイルを2回出そうとしています。刷り直しなら {{ m.b('はい') }}。
前回の状態が復元されています。条番号を再表示すると使用済み情報がリセットされます。続きから使うなら {{ m.b('いいえ') }}。最初からやり直すなら {{ m.b('はい') }}。
No…は既に存在します。上書きしますか？No指定で、すでにある番号を出そうとしています。

10困ったとき

出たもの・起きたことすること
該当するﾛｯﾄ情報が見つかりません。{{ m.b('取り込み') }} をしてから、もう一度ロット番号を入れます。それでも出ないときは台帳にまだありません。
前工程実績数が0です梱包課共有の仕掛にないロットです。{{ m.b('修正する') }} で手で入れます。
丈Nの重量が未入力です。その丈の重量を入れます。
積み上げが埋まっていません。積み条数の分だけコイルを押します。
包装仕様NO が「(未登録)」台帳の側にまだ登録がありません。担当に確かめてください。
この画面はすでに開いています梱包明細は1つの画面でしか使えません。先に開いた画面を使います。見当たらないときだけ {{ m.b('この画面で使う') }}。
エラー番号 E…番号を伝えてください。統合画面の {{ m.b('ログ') }} で中身を見られます。
