この説明書の読み方

  1. {{ m.n(1) }}写真の中の赤い丸数字と、説明の番号は同じです。番号の順に操作します。
  2. {{ m.n(2) }}{{ m.b('このように囲んだ文字') }}は、画面のボタンや項目の名前そのままです。
  3. {{ m.n(3) }}紙が要るときは、上の {{ m.b('印刷する') }} で、いま開いている説明書だけを刷れます(ファイルを保存する必要はありません)。
コツ統合画面の上の帯の {{ m.b('説明書') }} を押すと、いま見ているタブのツールの説明書が開きます。ダイアログの {{ m.b('別の窓で開く') }} を押すと、画面を見ながら横に並べて読めます。
