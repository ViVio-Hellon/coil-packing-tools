{% endblock %} {% block body %} {{ m.heading("はじめに・統合画面") }}

{{ display_name }}(VER{{ app_version }})は、梱包明細・ペナラベル・資材計算の3つのツールを、 1つの画面のタブで切り替えて使えるようにしたものです。ここでは3つのツールに共通のこと(起動・終了・画面の見方・版の見方)を説明します。 写真は試験用のデータで撮っています(ロット番号・名前などは作り物です)。

1起動する

起動のしかたは2つあります。ふだんはデスクトップ版を使います。

押すもの開くところ使うとき
コイル梱包ツール.exe(デスクトップ版)専用の窓ふだん。ネットワークの「ポート」を使わないので、ほかのソフトとぶつかりません
Start.vbs(ブラウザ版)ブラウザのタブexe が無いとき・動かないときの予備
  1. {{ m.n(1) }}アプリのフォルダの コイル梱包ツール.exe をダブルクリックします。窓がすぐ出て「起動しています」と表示されます。
  2. {{ m.n(2) }}台帳の取り込みが終わるまで、待機画面に進み具合が出ます。急ぐときは {{ m.b('待たずに使い始める ▸') }} で先に入れます(取り込みは裏で続きます)。
  3. {{ m.n(3) }}統合画面が出たら使えます。
注意デスクトップ版とブラウザ版は同時には動きません(同じデータを使うため)。片方が動いているときにもう片方を起動すると、理由が出て起動しません。動いているほうを終了してから起動してください。
コツ2回起動しても、2つ目は起動しません(開いている窓が前に出ます)。

2画面の見方

{{ m.fig("shell-overview", "統合画面。いちばん上の帯と、その下のタブは3つのツールで共通です。下の大きな部分が、選んだツールの画面です。") }}
  1. {{ m.n(1) }}タブ:{{ m.b('梱包明細') }} {{ m.b('ペナラベル') }} {{ m.b('資材計算') }} を押して切り替えます(ツールを切り替える)。
  2. {{ m.n(2) }}版:統合ツールの版です。押すと3つのツールの版の一覧が出ます(版の見方)。
  3. {{ m.n(3) }}画面の色:{{ m.b('自動') }} {{ m.b('ライト') }} {{ m.b('ダーク') }}(画面の色)。
  4. {{ m.n(4) }}{{ m.b('説明書') }}:この説明書を開きます。いま見ているタブのツールの説明書が出ます。
  5. {{ m.n(5) }}{{ m.b('ログ') }}:ログとエラーの記録を見ます(ログとエラーの記録)。
  6. {{ m.n(6) }}接続OK:アプリが動いている印です。赤い帯が出たら困ったときを見てください。
  7. {{ m.n(7) }}{{ m.b('終了') }}:アプリを終わります(3つのツールとも終わります)。

3ツールを切り替える

{{ m.fig("shell-tabs", "タブ。名前の右の小さな文字が、そのツールの版です。") }}
  1. {{ m.n(1) }}{{ m.b('梱包明細') }}:梱包明細表を出す(梱包明細の説明書)。
  2. {{ m.n(2) }}{{ m.b('ペナラベル') }}:テスラ向けの出荷ラベルと風袋計算(ペナラベルの説明書)。
  3. {{ m.n(3) }}{{ m.b('資材計算') }}:パレット・リプラ・緩衝材の員数と発注票(資材計算の説明書)。
コツタブを切り替えても、入力の途中の値や結果は消えません。途中で別のツールを使って、戻ってから続きができます。

4版の見方

版は統合ツールの版と3つのツールの版を分けて持っています。問い合わせるときは、この版を伝えてください。

{{ m.fig("shell-versions", "上の帯の版を押したところ。統合ツールと3つのツールの版が並びます。") }}
  1. {{ m.n(1) }}上の帯の版({{ m.b('VER' ~ app_version) }})を押します。
  2. {{ m.n(2) }}版の一覧が出ます。もう一度押すか、ほかの場所を押すと閉じます。
どれの版いまの版出ている場所
{{ display_name }}(統合ツール)VER{{ versions.app }}上の帯の左・この説明書のいちばん上
梱包明細VER{{ versions.details }}タブ・梱包明細の見出しの {{ m.b('VER ' ~ versions.details) }}(押すと「バージョン情報」)
ペナラベルVER{{ versions.pena }}タブ・ペナラベルの左上の「v{{ versions.pena }}」(となりは版を切った日)と、画面の下の帯
資材計算VER{{ versions.material }}タブ・資材計算の見出しの {{ m.b('VER' ~ versions.material) }}(押すと 設定 → このアプリ)

5画面の色

{{ m.fig("shell-theme-dark", "「ダーク」を選んだところ。統合画面と3つのツールの画面がそろって暗い色になります。") }}
  1. {{ m.n(1) }}{{ m.b('自動') }} {{ m.b('ライト') }} {{ m.b('ダーク') }} のどれかを押します。押すとすぐ変わり、このPCに覚えます。 {{ m.b('自動') }} は Windows の「色」の設定(ライト/ダーク)に合わせます。
コツ紙(明細表・ラベル・印刷用の画面)は、どれを選んでも白地に黒のままです。

6説明書を開く

{{ m.fig("shell-manual", "上の帯の「説明書」を押したところ。いま見ているタブのツールの説明書が開きます。") }}
  1. {{ m.n(1) }}{{ m.b('別の窓で開く') }}:説明書を別の窓(ブラウザ版では別のタブ)で開き直します。ツールの画面と並べて読めます。
  2. {{ m.n(2) }}{{ m.b('閉じる') }}:説明書を閉じて、ツールの画面に戻ります。

説明書の上の {{ m.b('目次') }} {{ m.b('梱包明細') }} などで、ほかの説明書へ移れます。紙が要るときは {{ m.b('印刷する') }} で、開いている説明書だけを刷れます(ファイルの保存は要りません)。

7ログとエラーの記録

{{ m.fig("shell-log", "上の帯の「ログ」を押したところ。エラーの記録・今日のログ・出力先の設定を見られます。") }}
  1. {{ m.n(1) }}{{ m.b('閉じる') }} で元の画面に戻ります。

ツールの画面に「エラー番号 E20261001-104512-3F9A」のような番号が出たら、その番号を伝えてください。{{ m.b('ログ') }} の「エラーの記録」で、何が起きたか・どの操作のときかを見られます。

8終了する

  1. {{ m.n(1) }}上の帯の {{ m.b('終了') }} を押します(デスクトップ版は、窓の右上の × でも同じです)。3つの機能とも終わります。
  2. {{ m.n(2) }}まだ保存していない入力があるときだけ、「まだ保存していない入力があります」と、どの機能のどの入力かが出ます。{{ m.b('OK') }} で(その入力は消えて)終わります。{{ m.b('キャンセル') }} ならそのまま使えます ── 保存してから、もう一度 {{ m.b('終了') }} を押してください。
  3. {{ m.n(3) }}資材計算の取り込みなど、途中の処理があるときだけ「実行中の処理があります … 中断して終了しますか?」と出ます。{{ m.b('キャンセル') }} で待ち、終わってから押してください({{ m.b('OK') }} だと中断して終わります)。

どちらも無ければ、確認は出ずにそのまま終わります(業務ツール統合ランチャーから閉じたときも同じです)。

保存していない入力として出るもの梱包明細: 7桁になっていない LOT No・「確定する」を押していない前工程実績数・設定の保存していない欄など。ペナラベル: 重量反映などのボタンを押していない新検番・重量・高さ、「決定」を押していない全サイズの入力など。資材計算: チェックリストへ積んでいない計算、記録していない発注票など(計算と発注票は止めると消えます)。

ブラウザ版は、画面のタブを全部閉じると、少しあとで自動で終わります。止まらないときは stop.bat を使います(開いている画面があれば、その画面に同じ確認が出ます)。

9困ったとき

出たもの・起きたことすること
「Python が見つかりません(または起動できません)」デスクトップ版の窓に出ます。このPCに Python が入っていません。窓に出ている入れ方のとおりに入れてから、もう一度開いてください。
「ブラウザ版のコイル梱包ツールが動いています」ブラウザの画面で {{ m.b('終了') }} を押すか、stop.bat で止めてから、デスクトップ版を開き直します。
「デスクトップ版のコイル梱包ツールが動いています」デスクトップ版の {{ m.b('終了') }} を押してから、ブラウザ版を起動します。
赤い帯「バックエンドと通信できません。アプリを開き直してください。」アプリが止まっています。開き直してください。
赤い帯「アプリが開き直されています」{{ m.b('読み込み直す') }} を押します。
「エラー番号 E…」番号を控えて伝えてください。{{ m.b('ログ') }} で中身を見られます。
ブラウザ版が起動しないstart.bat で起動すると、理由が黒い画面に出ます。
